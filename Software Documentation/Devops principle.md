1. **automate as much as possible** - eliminating repetitive manual tasks across building, testing, provisioning, and deployment to reduce human error
2. **collaboration and shared responsibility** - uniting development and operations teams so everyone shares accountability from planning through production
3. **continuous integration and continuous deployment (CI/CD)** - automating code merging, testing, and releasing updates to catch bugs early and ship updates safely
4. **monitoring and feedback loops**  - tracking real-time performance and system logs in production to fix issues quickly and guide future improvements.
5. **continuous improvement and blameless culture** - treating failures as learning opportunities rather than blaming individuals, helping teams iterate and innovate safely
